# ALTER Autopilot 0.1 — Android MVP

## Что реализовано
Android NotificationListenerService получает уведомления с согласия пользователя. Только для явно перечисленных package names и при включенном переключателе пытается отправить **фиксированный** автоответ через Notification.Action с RemoteInput. Применяет локальный фильтр опасного содержания, подавляет дубликаты в памяти процесса и записывает краткий журнал. Никакой ИИ-модели в 0.1 нет: это проверяемый автономный каркас.

## Сборка на Android без ПК
1. Установите AndroidIDE из официального проекта (проверьте совместимость устройства и наличие JDK 17, Android SDK 34 и Gradle 8.2).
2. Распакуйте архив в папку на телефоне. Откройте `ALTER-Autopilot` как Gradle-проект в AndroidIDE.
3. При необходимости установите SDK 34 через SDK Manager AndroidIDE, дождитесь Gradle Sync. Для AGP 8.2.2 нужен Gradle 8.2 и JDK 17.
4. Соберите debug APK (`assembleDebug`). Если AndroidIDE не предоставляет Gradle 8.2, используйте его встроенную настройку совместимой версии; исходники могут потребовать адаптации к установленной среде.
5. Установите APK и разрешите установку приложений из выбранного файлового менеджера/IDE.
6. Откройте ALTER, впишите **точный package name** тестируемого мессенджера (например, `org.telegram.messenger` — только если он соответствует вашей установленной сборке), задайте текст ответа, включите переключатель и сохраните.
7. Нажмите «Открыть доступ к уведомлениям» и разрешите доступ ALTER в системных настройках.
8. Попросите знакомого отправить тестовое сообщение, когда есть уведомление с кнопкой «Ответить». Проверьте журнал и фактическую доставку в мессенджере.

## Ограничения
- Поддержка RemoteInput зависит от приложения, версии ОС, формы уведомления и его текущего состояния.
- `PendingIntent.send()` означает запрос к приложению, а не подтверждение доставки собеседнику.
- Локальная проверка по регулярным выражениям не гарантирует безопасность или точность.
- После перезапуска процесса временный список дубликатов очищается. Автоответы могут повториться.
- Некоторые Android-прошивки ограничивают фоновые процессы, а отключение доступа к уведомлениям прекращает работу.
- Не использовать для массовых сообщений, спама, чувствительной переписки или финансовых операций.
- Перед реальным использованием требуется долговременное хранилище дедупликации, контакты/диалоги allowlist, лимиты отправки, явное отключение и более строгая проверка.

## Облачная сборка APK через GitHub Actions (без компьютера)
1. На github.com создайте новый репозиторий, например `alter-autopilot`, с видимостью **Private**. Не добавляйте README при создании.
2. Загрузите **содержимое папки** `ALTER-Autopilot` в корень репозитория. Важно: GitHub должен видеть `settings.gradle.kts`, `app/` и `.github/workflows/build-apk.yml` прямо в корне. Некоторые файловые менеджеры скрывают папки, начинающиеся с точки: включите показ скрытых файлов.
3. Откройте вкладку **Actions**, выберите `Build ALTER APK` и нажмите **Run workflow** (или дождитесь автоматического запуска при push).
4. После успешной сборки откройте выполненный workflow и скачайте artifact `ALTER-Autopilot-debug-apk`. Распакуйте скачанный ZIP: внутри `app-debug.apk`.
5. Установите APK на Android, подтвердив установку из выбранного источника. Для тестов сначала используйте только тестовый чат и конкретное приложение.

Это debug APK, подписанный временным ключом сборщика. Для обновлений без переустановки потребуется постоянный ключ подписи. Проект не был собран и протестирован в этой среде; если сборка выдаст ошибку, сохраните лог GitHub Actions.
